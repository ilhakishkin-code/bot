# Бот для розыгрышей (тестовая версия, без рандома)

## Запуск
1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, впишите `BOT_TOKEN` и `ADMIN_IDS`
3. `python main.py`

## Как работает
- Пост в канале публикуется с URL-кнопкой `t.me/<бот>?start=g_<id>`: она работает и в репостах.
- Участие: нажатие -> /start в боте -> проверка подписок -> билет. Рефералы: `g_<id>_r<user_id>`.
- Победителей выбирает админ вручную (рандом не реализован).
- Админ-панель: /admin или кнопка «🛠 Админ-панель».

## Меры против блокировок / жалоб
- Бот пишет только тем, кто сам нажал Start (участники приходят по deep-link).
- Рассылки только по действию админа, только участникам одного розыгрыша, с подтверждением и предпросмотром.
- Скорость ~16 сообщений/сек (лимит Telegram ~30/сек), обработка 429 (retry_after), 403 -> участник помечается и больше не получает сообщений.
- Защита от дублей: один и тот же тип напоминания повторно — только с явным подтверждением; параллельный запуск той же рассылки блокируется.
- Кнопка «Отключить уведомления» у каждого участника.
- Антифлуд на действия пользователя, лимиты: 5 каналов подписки, до 100 победителей.
- Права проверяются: бот — админ канала, создатель — админ канала.
- Хранятся только user_id, username, имя.

## Анимированные эмодзи
- Берутся из наборов (см. `custom_emoji.py`). Нужный эмодзи подбирается автоматически по обычному
  (например, `🗑` в тексте кнопки становится анимированной иконкой). Если в наборе нет — берётся похожий
  из `ALIASES`, а если и его нет — остаётся обычный.
- Работает, только если у владельца бота (аккаунт, создавший его в @BotFather) есть Telegram Premium.
- Наборы по умолчанию: `RestrictedEmoji` и `NewsEmoji` (если эмодзи есть в обоих — берётся из первого; звёздочки и
  настройки закреплены за `NewsEmoji`, см. `PREFER` в `custom_emoji.py`).
- Переменные (необязательные): `CUSTOM_EMOJI=0` — выключить, `CUSTOM_EMOJI_SETS=Набор1,Набор2` — свои наборы.
- Админу: команда `/emojis` показывает, какие эмодзи найдены, а каких нет в наборах.
- При старте в логах видно, какие эмодзи нашлись и каких нет в наборе.
